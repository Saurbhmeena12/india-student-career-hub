Design direction

Premium white, zero dependencies

The whole site was rebuilt on one quiet design system: white canvas, ink type, a single deep-indigo accent, hairline borders instead of shadows.

No CDN, no external fonts

System font stack and a hand-drawn inline SVG icon set (74 icons) that hydrates <i class="fas fa-…"> at runtime. The site renders identically offline, on a slow connection and inside a sandboxed preview.

One card, every opportunity

js/cards.js renders jobs, scholarships, schemes, courses, training, internships, apprenticeships, exams and portals through a single spec-driven component, so no two listing pages drift apart.

Dark mode by token swap

Ink and surface variables invert under [data-theme="dark"]. Every page, the admin console and the AI search answer panel follow automatically.

Responsive from 360px

Auto-fill grids, a slide-in drawer under 1100px, wrapping chip rows and a clamp() type scale. No horizontal scroll at any width.

New this build

Three tools that turn a directory into a decision

The site no longer just lists opportunities. It answers the two questions a student actually has: can I apply? and by when?

Eligibility Finder new

Four answers — qualification, state, category, and optionally age and income — produce a filtered, ranked list across jobs, scholarships, schemes and courses. Every result states why it matched, and anything ambiguous is labelled “check notification” rather than silently dropped.

Deadline Calendar new

Every closing date from four tables merged into one month view, with a “closing in 7 days” strip and one-click .ics export so a date can be dropped into any calendar app without an account.

Study Material new

Eighteen official, legally linkable resources — NCERT, ePathshala, NROER, NPTEL, SWAYAM, eGyanKosh, SSC, UPSC, NTA, NIELIT, NDLI. Nothing is hosted here, so no copyright is broken and every link stays current.

What this changes

Before: a student had to read 144 records and guess. Now: four questions, a ranked shortlist with reasons, and a calendar that says exactly which date is about to expire.

Cost

Hosting

Oracle Cloud Always Free VM (PM2 + Nginx + Certbot), or Render free tier with the database held in Turso.

Database

Local SQLite by default. Turso free plan (5 GB, no card) when the host has an ephemeral disk.

AI

Gemini 2.5 Flash free tier, capped at 400 requests/day. With no key the assistant falls back to pure database retrieval — still free.

Domain

is-a.dev subdomain via a GitHub pull request, or a Render subdomain immediately. No registrar fee.
